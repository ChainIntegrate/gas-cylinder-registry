How it works

Each cylinder has its own record: gas, where it is, whether it is full, empty or defective, and all its movements. The records update themselves with each of the driver's documents.

  • The owner uses the page gastrace.chainintegrate.it on a computer: sees cylinders and documents, manages customers, phones and settings.
  • The driver uses the GasTrace app on an Android phone: scans the cylinders' barcodes at delivery and collection.
  • After each document an e-mail goes to the customer and to the company.
  • The data is encrypted: only the owner's data password opens it. The company pays nothing per operation: ChainIntegrate takes care of it.

For the owner

First sign-in

Use the computer where the ChainIntegrate Account extension is installed in the browser, with the company's account.

  1. Open gastrace.chainintegrate.it and press Sign in with ChainIntegrate Account.
  2. The extension's window opens: check that the site is gastrace.chainintegrate.it and confirm.
  3. The page finds the company's cylinder register by itself. If there is more than one, choose the right one.
  4. Type the data password and press Open. It takes a few seconds.

If the page cannot find the extension, install it from account.chainintegrate.it, or open the page in the browser where it is installed.

Each change (a customer, a phone, the settings) is confirmed in the extension's window. Pressing Cancel there changes nothing.

Data password and recovery code

  • The data password opens the cylinders' data. It stays in the page, is never sent anywhere, and is forgotten when the page closes.
  • The recovery code is 24 words, handed to you once when the register was created. Keep it printed in a safe place, away from the computer. Do not photograph it or e-mail it.
  • Lost the password: on the password screen press I lost the password, type the 24 words and choose a new password.
  • To change it: Settings → Change password. Phones already set up keep working.

Without the password and the recovery code nobody, ChainIntegrate included, can read the data any more.

A good password is a sentence of at least 20 characters, or at least 14 characters mixing lower case, upper case, digits and symbols.

Settings (do these first)

  • Company name: shown in the app and in the e-mails' subject. Until it is set, the app warns the driver.
  • Your company's e-mails: the company's mailboxes (office, warehouse…) that receive a copy of every document, for all customers. Separate them with commas.

Customers and refill plants

  • Customers → Add customer: name and e-mails. The customer's e-mails receive each document about them.
  • Add refill plant: where the cylinders go to be refilled.
  • Edit changes the name or e-mails; Remove takes it off the app's list, but documents already recorded stay.

The driver sees the updated list the next time the app is opened.

Drivers' phones

Each phone is authorized once, with the driver next to you. The Phones section shows the setup QR code.

  1. The driver installs the app (see below) and opens it: scans the QR on the computer's screen.
  2. The app has the driver create the phone's key with fingerprint or PIN, then shows the phone's code (groups of 4 characters).
  3. You type that code in Authorize a phone, press Authorize and confirm in the extension.
  4. The app notices by itself and asks for the data password: you type it on the phone, once. The phone does not keep it.

Revoke a phone that is lost, stolen, or belongs to a driver who no longer works with you: from then on it cannot record anything.

Cylinders and documents

  • Overview: how many cylinders at the depot, at customers, being refilled, defective; by gas; the latest documents.
  • Cylinders: search by code, gas or customer. Click a cylinder to see its whole history, movement by movement.
  • Documents: delivery notes, stock counts and refill notes, with their cylinders and the warnings the driver confirmed.

Refresh reloads the data after a new document.

Downloading the data

In Download data you can save the register's data on the computer, as files to open with Excel or LibreOffice (double-click the file):

  • Cylinders: each cylinder with its gas, litres, owner, where it is, condition and last movement;
  • Movements: one row for each cylinder of each document, oldest first;
  • Documents: one row per document, with how many cylinders were delivered, collected, counted or refilled;
  • Customers and refill plants: names and e-mails.

The files are made in the page itself: the data goes through no server. The file name carries the date, so you can keep a copy each month.

The downloaded files are not encrypted: they hold the customers' names and e-mails. Keep them as the company's other documents.

For the driver

Installing the app

The GasTrace app is for Android phones. It is not on the Play Store: it is downloaded from GitHub.

  1. On the phone open the latest version of GasTrace and tap the gastrace-v….apk file to download it.
  2. Open the downloaded file. The first time Android says it cannot install apps from this source: tap Settings, turn on Allow from this source, go back and the installation goes on.
  3. Play Protect may offer to scan the app because it does not come from the Play Store: accept the scan, or tap More details → Install anyway. It is Google's check of apps that do not go through its store, not a problem of the app.

The phone needs a screen lock (fingerprint, PIN or pattern): without it the app cannot protect its key.

Never uninstall the app or clear its data: the phone's key would be lost and the phone would have to be set up again with the owner.

Setting up the phone (once, with the owner)

  1. Open GasTrace and tap Scan the code: scan the QR the owner shows on the page.
  2. Tap Create the key and confirm with fingerprint or PIN.
  3. The app shows this phone's code: give it to the owner (you can use Copy).
  4. Once the owner has authorized it, the app asks for the data password: the owner types it.

From then on open the app with Unlock with fingerprint or PIN.

Delivery and collection

  1. Tap Delivery / collection and choose the customer.
  2. Tap Scan cylinder for each cylinder, those you leave and those you take back. If the code cannot be read, use Type the code.
  3. The app proposes the movement by itself:
    • a cylinder at the depot, or never seen before, is a delivery (full);
    • a cylinder that was already at this customer is a collection (empty; full or defective can be chosen).
  4. For a new cylinder choose the gas (and the litres if you like).
  5. If a warning appears (for example "Recorded at another customer"), check it and tap I confirm the warnings: they are listed in the e-mail too.
  6. Type the delivery note number, check the summary and who gets the e-mail (you can add an address), then Send and confirm with fingerprint or PIN.

"Recorded" means the document is saved; then the app says whether the e-mail left.

Stock count

Used at the start, to record the cylinders already at customers or refill plants, and whenever a count is needed.

  1. Tap Stock count and choose the customer or plant.
  2. Scan all the cylinders there; for new ones choose the gas.
  3. Send. No document number is needed and no e-mail leaves, unless you add an address.

Refill

Tap Refill and choose the refill plant. Scan the cylinders: those at the depot are sent to refill, those that were at that plant are back from refill. Type the document number and send.

Checking a cylinder

Check a cylinder: scan the code and see the gas, where it is, its condition and last movement. It records nothing.

No network: "To send"

Without signal the document is saved on the phone and leaves by itself when the network returns. The home screen shows To send (n): there you can see them, send them with Send now or discard them.

If meanwhile someone else recorded one of the same cylinders, the app says "A cylinder changed in the meantime": make the document again.

The document's e-mail

After each delivery note or refill note an e-mail goes to the customer's e-mails, the company's e-mails and any address added in the document. If the app says the e-mail did not leave, or it does not know whether it left, tap Send from the phone: your e-mail app opens with the text ready.

Updating the app

When a new version is out, the home screen shows "A new version of GasTrace is available". Tap Download, open the downloaded file and confirm: the new version installs over the old one and the phone stays set up. The installed version is written at the bottom of the home screen.

Common problems

"A cylinder changed in the meantime"

Someone recorded the same cylinder after you scanned it. Make the document again: the app proposes the updated movements.

"This document is already recorded"

The same document number was already sent. Look in "To send", or ask the owner to look in Documents.

"This phone is no longer authorized"

The owner revoked it. If that was a mistake, it has to be set up again.

Phone lost, stolen or replaced

The owner revokes it at once in Phones. The new phone is set up from scratch, like the first time.

The fingerprint no longer works, or the screen lock was removed

Android deletes the app's key when the screen lock is removed. Set the screen lock again and set up the phone again with the owner; the owner revokes the old code.

The page cannot find the extension

Open the page in the browser where ChainIntegrate Account is installed, or install it from account.chainintegrate.it.

"Wrong password"

Check upper case and the keyboard. If it is lost, use I lost the password with the recovery code.

Anything else

Write to ChainIntegrate saying what you were doing and the message you saw.
